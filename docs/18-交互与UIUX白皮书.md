# 3MF模型管理器 · 交互与 UI/UX 白皮书

> 版本：v1.1　更新日期：2026-11-22
> 适用范围：主模型库（网格 / 列表）、打印回执、重复文件、失效文件、详情抽屉
> 本文是交互一致性的**约束文档**：新增视图或批量操作时，必须先对照这里的规则，再写代码。

---

## 一、总则：交互一致性六条

1. **同一手势，同一含义。** 长按 480ms 在任何卡片列表里都只表示一件事：进入编辑模式并选中按下的那一项。
2. **同一位置，同一动作。** 编辑模式的操作条固定在屏幕底部居中；「全选」「删除」「完成」的位置和顺序不随视图改变。
3. **勾选状态只有一个来源。** 全局 `state.selection`（Set）是唯一选择集；视图只在渲染时读它，不各自维护副本。
4. **危险操作必须分级且可确认。** 删除「模型文件」「回执记录」「单个副本」是三种不同危险级别，确认文案必须说清删的是什么、能否恢复。
5. **不做无声的破坏。** 任何删除都要二次确认；能恢复的走系统回收站，只删记录的要明说「不动模型文件」。
6. **视图隔离。** 切换视图时退出编辑模式并清空选择集；模型 id 与回执 id 绝不共用同一批勾选。

## 二、长按编辑模式（核心交互）

### 2.1 进入

| 规则 | 值 | 说明 |
| --- | --- | --- |
| 触发手势 | 在卡片上按住不动 | 鼠标左键 / 触摸均适用 |
| 时长 | **480 ms** | 主页面与回执视图完全一致 |
| 位移容差 | **8 px** | 超出即判定为拖动，取消长按 |
| 进入时 | 立即选中按下的那一项 | 操作条显示「已选 1 项」，不用再点一次 |
| 抑制误触 | 吞掉松手后的那次 click | `suppressClick`，避免进入模式又立刻取消选中 |
| 不触发区域 | 按钮、输入框、标签、链接 | 长按这些元素不进编辑模式 |

### 2.2 编辑模式中的行为

- 单击卡片 = **切换勾选**（不会打开详情、不会启动切片软件）。
- 卡片左上角显示勾选框；选中项用主题强调色描边 + 浅色底。
- 顶部统计条右侧的「模型批量操作」必须隐藏——它在回执视图里是危险的（见 §4.2）。
- 拖动仍然可用于归类；点快捷按钮仍然生效。

### 2.3 操作条（editbar）

统一结构，固定在底部居中：

```
[编辑模式] [已选 N 项] ── [全选] [迁移到分类] [删除] [完成]
```

- **全选**：只选当前视图可见的那些项；已经全选时按钮禁用。
- **迁移到分类**：只在模型库视图出现；回执视图必须隐藏（返回 `hidden`）。
- **删除**：按视图分发到各自的处理器，文案随视图变化（模型 = 「删除」，回执 = 「删除回执」）。
- **完成**：退出编辑模式并清空选择集。

### 2.4 退出

按优先级逐层关闭，一次按键只关一层：

1. 点击「完成」
2. 按 `Esc`
3. 点击空白区域（卡片本身不算空白）
4. 切换视图 / 刷新导致 `contentMode` 改变

退出时：清除 `state.editMode`、移除 body 的 `edit-mode` 类、隐藏操作条、清空选择集。

## 三、各视图的操作矩阵

| 视图 | 长按进入 | 可选操作 | 删除按钮实际动作 | 选择集内容 |
| --- | --- | --- | --- | --- |
| 模型库（网格 / 列表） | ✅ | 全选 / 迁移分类 / 删除 | `api.trash(ids)` → 系统回收站，可恢复 | 模型 id |
| 打印回执 · 成本账本 | ✅ | 全选 / 删除回执 | `api.receiptsDelete(ids)` → 只删本机回执记录 | 回执 id（`rcp-…`） |
| 重复文件 | 按普通卡片规则 | 同上（模型语义） | 同模型库 | 模型 id |
| 失效文件 | 按普通卡片规则 | 同上（模型语义） | 同模型库 | 模型 id |
| 详情内副本切换 | ❌（用行内按钮） | 切换 / 删除单个副本 | `api.trash([单id])` → 回收站 | 不使用选择集 |

**视图隔离实现要点**

- `app.js`：视图切换时若 `contentMode` 改变且在编辑模式，调用 `exitEditMode()`；`pruneSelection()` 在回执视图直接跳过（回执 id 不在模型列表里，会被误裁掉）。
- `bulkbar.js`：`syncBulkbar()` 在回执视图隐藏模型批量操作条。
- `app.js isBlankClick()`：`.rc-card` 与 `.card` 同属「内容」，点击不触发退出。
- `editmode.js`：`scopeTotal()` 按视图取总数（回执数来自渲染时写入的 `window.__receiptsIds`）。

## 四、删除安全规范

### 4.1 三个危险级别

| 级别 | 场景 | 确认文案必须包含 | 可恢复 |
| --- | --- | --- | --- |
| 高 | 删除模型文件（批量 / 单个） | 「移入系统回收站」「列出完整路径」 | ✅ 回收站 |
| 中 | 删除重复组里的单个副本 | 「只删除这一个副本」「其他副本不受影响」 | ✅ 回收站 |
| 低 | 删除打印回执记录 | 「只删除本机的回执记录，不会动模型文件或模型库」 | ❌ 明确说明 |

### 4.2 严禁串味

- **回执视图绝不调用 `api.trash()`**：那会按回执 id 去删模型文件，可能造成真实数据丢失。
- **模型批量操作条在回执视图必须隐藏**：否则上面的「删除」按钮会走模型删除路径。
- **回执选择集不能被模型列表裁剪**：`pruneSelection()` 必须按 `contentMode` 分流。
- 所有删除都要先 `confirmDialog`，失败逐条报告，成功后再刷新数据并退出编辑模式。

## 五、重复文件交互

普通视图中内容哈希相同的文件只显示一张代表卡，角标「重复 ×N」。

- **主页不提供展开入口**：卡片只有「重复 ×N」角标，不放「展开 N 个副本」按钮。要看同组其他文件就点开卡片，在详情里切换。
- 详情大图下方列出同组每个副本的完整路径，并显示各自的打印状态、大小、添加时间、备注摘要。
- 切换副本三种方式等价：点行、点「上一个 / 下一个」、按 `←` `→`。顶部显示「第 N / M 个」。
- 切换带轻微方向性淡入；**不弹 toast**——高亮、位置数字、主图切换已是即时反馈，连续切换时提示会堆叠遮挡界面。
- 副本行右侧垃圾桶 = 只删这一个副本（见 §4.1 中等级）。
- 侧栏「重复文件」视图仍按组展示全部成员，用于批量清理。

## 五之二、耗材库与默认耗材

- **只允许手动新建耗材**：不提供「从预设添加」或自动探测入口，列表里出现的都是用户自己加的。
- **筛选下拉用 `change` 事件**：原生 `<select>` 的点击不能在 click 阶段 `render()`，否则下拉刚弹出就被整块 DOM 替换、瞬间消失（2026-11-22 实际bug）。所有「改了就重绘」的控件统一走 `change`，click 阶段只做选中/打开。
- **默认耗材**：详情栏「设为默认」按钮单选一个耗材，卡片显示「默认」角标、按钮变「已是默认」；再点一次取消。删除默认耗材时自动清空默认指向，不留悬空 id。
- **默认耗材计价**：模型既没有 `filamentLinks`、也没有切片逐耗材用量时，按 `可信重量 × 默认耗材单价` 估算成本，`source='default'`，卡片显示具体金额（不再是 `¥??`），详情来源标注「按默认耗材估算」。设置/取消默认会触发成本重算。

## 六、视觉与反馈约定

- **反馈优先级**：DOM 状态变化（勾选 / 高亮 / 位置数字） > 轻量动画 > toast。能用前两者表达就不要弹 toast。
- **动画**：WAAPI 轻量淡入，时长 140–180 ms，位移 4–14 px；同模型局部刷新不播动画，避免每次点收藏都像重开窗口。
- **toast 只用于**：操作结果（成功 / 失败 / 需用户注意）、无法用界面状态表达的提示。错误 toast 必须可追溯（探针会监听 `.toast-error`）。
- **危险色**：仅用于删除按钮的 hover 态与确认弹窗；常态保持低调，不喧宾夺主。
- **来源链接状态**：卡片地球按钮由 `sourceUrl` 唯一决定视觉状态——有合法 `http(s)` 链接时加 `has-source`，显示语义绿底白图标；没有链接时保留原灰色，不显示可点击暗示。网格与列表视图必须一致，hover 只做同色系微调，不回落成灰底。
- **溢出**：长路径统一 `text-overflow: ellipsis` + `title` 全称提示；详情行内元数据最多两行，不换行撑高。

## 七、实现与验证约定

### 7.1 模块职责

| 文件 | 职责 |
| --- | --- |
| `components/editmode.js` | 编辑模式状态、操作条、按视图分发删除动作 |
| `components/bulkbar.js` | 模型批量操作条；回执视图必须隐藏 |
| `views/grid.js` | 模型卡片长按、勾选、全选 / 清空事件 |
| `views/receipts.js` | 回执卡片长按、勾选、回执删除确认 |
| `app.js` | 视图切换退出编辑模式、选择集裁剪、Esc 逐层关闭 |

### 7.2 走查探针

新增交互必须配一个 UI 探针，且**不得修改用户真实数据**：

- `tools/probe-dupfold.js`：重复文件折叠、副本切换、单副本删除按钮结构。
- `tools/probe-receipts-edit.js`：回执长按、多选、全选、删除确认（点「取消」不落盘）、Esc 退出、模型批量条隐藏。
- `tools/probe-source-url.js`：来源链接识别、`data-url` 一致性、地球按钮绿/灰状态（网格 + 列表）、详情展示。

探针必须断言 `toastErrors: []`——被 catch 后只弹红字的运行时错误（如漏 import）肉眼容易漏掉。

### 7.3 回归清单

改动交互逻辑后至少跑：

```bash
npm test
npm run selftest
node tools/check-ipc-contract.js
node launch.js --capture=data/ui-xxx.png --ui-script=tools/probe-xxx.js
```
