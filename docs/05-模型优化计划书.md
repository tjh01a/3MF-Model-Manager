# 05 · 模型优化功能 可执行计划书

> 依据：`04-模型优化调研结论.md`（全部结论均来自真实样本实测）
> 目标：在 PrintShelf 里加一个**离线、无损、可量化**的「模型体检 + 表面优化」功能，把 AI 生成/拆件 3MF 的表面折角压下去，同时完整保留拆件结构与原文件。
> 阶段：本文件为阶段二成果；阶段三按本计划实施。

---

## 1. 目标与边界

**做**：读 3MF → 体检 → 用本机 Blender 做顶点滤波 → 无损写回成**新 3MF** → 给量化报告 + 打印建议。
**不做**：改原文件、改用户切片参数、补洞/雕模、重新分色分件、3D 实时编辑、云处理、非 3MF 格式。

一句话红线：**原 3MF 与 `data/library.json` 都不允许被优化过程写入。**

## 2. 功能模块

| 编号 | 模块 | 职责 | 主要文件（新增/修改） |
|---|---|---|---|
| **M1** | 3MF 结构解析与体检 | 枚举 ZIP 内所有 `.model`；逐件解析 V/F；计算夹角分布/细长三角/流形/体积/bbox；识别拆件工程与棱角件；只读 | `src/core/mesh3mf.js`（新） |
| **M2** | PLY 桥接 | 逐件导出二进制 PLY 到临时目录；读回优化后的坐标；校验顶点数与索引一一对应 | `src/core/mesh3mf.js`（新） |
| **M3** | Blender 编排 | 探测/校验 Blender；生成参数化 Python 脚本；`spawn` 无头执行；进度/取消/超时；解析 JSON 报告 | `src/core/meshopt.js`（新）、`tools/blender/mesh_opt.py`（新） |
| **M4** | 安全写回 | 逐顶点位移 clamp；按序替换 `<vertex>` 坐标；其余 ZIP 条目字节级复制；输出新文件；写前后结构校验 | `src/core/mesh3mf.js`（新） |

## 3. 交互流程

### F1 主流程（最少步骤）
```
选中模型（或详情面板） → 点「模型体检」
   → 弹窗体检卡：11 部件 / 950,930 面 / 封闭流形 ✅ / >15° 边 14% / 细长 8.7%
   → 三档 + 位移上限（默认 标准档 0.15 mm）
   → 点「开始优化」
   → 进度条（解析 → 导出 PLY → Blender 处理 N/11 → 写回 → 校验）
   → 完成页：前后指标对比表 + 跳过部件清单 + 打印建议 + [加入模型库] [用切片软件打开]
```

### F2 档位
| 档 | 参数 | 顶点数 | 适用 |
|---|---|---|---|
| 温和 | `SMOOTH factor=0.3, iters=4`，clamp 0.10 mm | 不变 | 已经比较光滑、只想轻微改善 |
| **标准（默认）** | `SMOOTH factor=0.6, iters=8`，clamp **0.15 mm** | 不变 | 本样本这类 AI 拆件 |
| 较强 | `SMOOTH factor=0.8, iters=12`，clamp 0.20 mm | 不变 | 折角明显，可接受轻微细节损失 |
| 深度（可选） | `VOXEL_REMESH voxel=0.25 mm` | **会变** | 细长三角极多；开启前二次确认，说明会重建部件、需重新切片 |

### F3 自动保护
- 体检时把「原始夹角 p90 > 60°」或「>30° 占比 > 20%」的部件标为**棱角件**，默认**跳过**（用户可手动强制包含，但会警告）。
- 所有档位写回前一律做位移 clamp；超过上限的顶点按比例缩回。
- 输出固定为 `原名_已优化.3mf`；重名自动加 `_2`、`_3`，**绝不覆盖**。

### F4 取消 / 失败
- 取消 → kill Blender 子进程 + 清理临时目录 + 删除半成品输出。
- 任一环节失败 → 中文原因 + 保留原文件 + 不产出半成品；写回校验不过 → 丢弃输出并报错。
- 超时：整体 5 min，Blender 单进程 3 min。

### 核心层（CommonJS，可在纯 Node 下测）
```js
// mesh3mf.js
inspect3mf(filePath) -> Promise<{
  ok, format, entries, mainModel, parts: [{
    entry, objectId, name, vertexCount, faceCount,

  ok, outPath, bytes, unchangedEntries, verified, report

measureGeometry(V, F) -> { angleMean, angleP90, gt15, gt30, thinPct, volumeMm3, bboxMm, boundary, nonmanifold }
```

```js
// meshopt.js
class MeshOptimizer extends EventEmitter
```

### IPC（channel 统一 `shelf:<name>`）
| channel | 入参 | 返回 |
|---|---|---|
| `meshInspect` | `id`（模型库记录 id） | 体检结果 |
| `meshBlender` | — | `{path, version, ok, reason}` |
| `meshBlenderSet` | `path` | 写 settings |
| `meshOptimize` | `{id, preset, clampMm, voxelMm, includeAngular, addToLibrary}` | `{ok, outPath, before, after, skipped, tips, addedToLibrary}` |
| `meshCancel` | — | `{ok}` |

主→渲染事件：`mesh:progress`、`mesh:log`、`mesh:done`、`mesh:error`。

## 9. 关键设计决策（ rationale ）

1. **Blender 只做计算，不碰 3MF**：它无 3MF 导入器；用 PLY 做中间格式，导出后顶点顺序与输入一致（实测 `np.array_equal(F0,F1)=True`），这才让「只替换坐标」成立。
2. **只替换 `<vertex>` 坐标，不重建 XML**：实测 33/33 其它条目字节一致。这样拆件、变换、切片配置、颜色、缩略图零风险保留，也避免 3MF 方言兼容问题。
3. **强制位移上限**：Blender 原生输出有 1,264 个顶点位移 >1 mm；clamp 到 0.15 mm 后效果几乎不丢、体积只变 −0.25%，是安全闸门。
4. **自动跳过棱角件**：实测 `object_5` 平滑后体积 −7%~−22%，属于拆件结构件；用「原始夹角 p90」自动识别。
5. **不写回切片配置**：层高/熨烫等只作建议，避免擅自改变用户打印参数；同时提示「几何已改，需重新切片」。
6. **输出新文件、绝不覆盖**：延续上次误删事故的教训，所有破坏性动作都只在副本上发生。
7. **体素重网格默认关闭**：效果最强但会改变顶点数、抹掉亚体素细节、让切片统计失效，必须显式二次确认。

## 10. 与既有能力的关系

- 复用 `figure_tool/core_smooth.py` 的**度量口径**（相邻面夹角分布）与**参数经验**（0.6×8）；不复用它的缩放/单件 STL 导出逻辑。

- 新增能力不改动 `src/core/library.js`、`store.js`、`scanner.js` 的任何一行。
